## Daily work

> Project was split into server and client. Server should do all the elo calculations, database access in the background and beforehand,since ideally it should be running constantly. So the results should be already in the database so the client gets results very quick.
Client is just the webpage that uses React, so the purpose it has is to solve the tasks from the user input by talking with the server. No direct connection with the database here. It sends requests to the endpoints on the server which then connects with the database.   

> I created an MySQL database locally. In the server directory there is a initializeDatabase.js file that does all the work that is split up in the other .js files.  

> I created a server that has 2 main tasks: 

Dealing with the CORS issue be action as a proxy server so that I can access all the data I need for my database. 
    
Accesing the database via defined endpoints. Here for displaying e.g. results of the week, or also for accessing elo, prediction algorithms of the server.

> I implemented a simple ELO algorithm that calculates the ELO for any club over all games in the database (calculateElo.js)

> I added a config.js file in the server which contains the data for accessing the database and every webpage that I want to access where I extract information for my database.
