# Meeting Minutes

Let's make sure we keep track of our meetings! We should create meeting minutes for every session. To help you out, we provide a handy [template](template.md) to use. Save the meeting minutes in the format `YYYYMMDD.md` so that we can easily refer back to them later.

[Source of the provided template](https://github.com/gong-sh/minutes-of-meeting-markdown/blob/master/minutes.md)
